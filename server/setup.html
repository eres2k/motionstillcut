First-use setup — two choices, and the editor opens. Everything here can be changed later at /setup or on the app's own Setup page.

1 · Where should your work live?

Browser-only mode talks to the engines directly, so each needs CORS switched on once: start ComfyUI with --enable-cors-header; in LM Studio enable CORS under Developer settings; for Ollama set OLLAMA_ORIGINS=*.

2 · Where are the engines?

Neither has to be running right now — the app's Setup page probes them again any time, and nothing else depends on them being up.
